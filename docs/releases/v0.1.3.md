## Changes

- **Favourites are kept for good.** Every Tropix on the MPC now shares one favourites list. A star stays in every
  project and every new instance until you take it off, and a star set or removed in one open Tropix shows in the
  others right away.
- **Favourites survive upgrades.** The list is saved in the plugin folder's `user/` folder, which installing a new
  version keeps.
- Projects saved with favourites from 0.1.2 or earlier add them to the shared list when they open.

## Fixes

- A new Tropix (or a new project) no longer starts with an empty ★ LIST.
