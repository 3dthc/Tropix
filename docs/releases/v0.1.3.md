**Tropix 0.1.3** for Akai MPC standalone devices (native ARM VST2).

- **Favourites stay.** A star used to live only in the project it was set in, so a new Tropix (or a new project)
  started with an empty ★ LIST. Now every Tropix on the MPC shares one list, kept in `engine/favorites.txt` next to
  the instruments: a star stays until you take it off, in every project and every new instance; two Tropix open at
  once stay in step; a project saved with stars of its own (0.1.2 and earlier) adds them to the list when it opens;
  upgrading Tropix keeps the file.

Check on the device: star a preset, add Tropix to another track (or start a new project): ★ LIST shows it. Restart
the MPC: still there. Take the star off: gone everywhere.

Install: put the zip for your MPC on it and install it like any other plugin (INSTALL.md is inside the zip). Projects
saved with earlier versions open with their sounds and settings.
